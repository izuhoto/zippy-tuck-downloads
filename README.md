# ZippyTuck Downloads

This repository hosts the distribution site content for **ZippyTuck**, a menu bar window management app for macOS.

ZippyTuck helps you move and resize macOS windows quickly with keyboard-centered modal controls and mouse-based global quick operations. You can enter ZippyTuck mode with a configurable shortcut, adjust the focused window with Vim-style commands, use grid positioning and edge snapping for precise placement, or move and resize the window under the cursor directly with modifier-key mouse gestures.

## Platform

- macOS 14 (Sonoma) or later

## Key Features

- Native macOS menu bar app for fast window moving and resizing
- Vim-style modal workflow with normal, move, and resize modes
- Global Quick Ops for modifier-key mouse move, resize, direction-snap move, and direction-snap resize without entering ZippyTuck mode
- Corner shortcuts for placing the active window at the screen's visible-frame corners
- Live HUD and target-window highlight while operating
- Configurable startup shortcut, global quick operation bindings, grid size, language, snap preferences, and Command-Q quit behavior
- English and Japanese UI, with optional system-language following
- First-launch Terms and Disclaimer agreement, About links, and web-distribution update checking
